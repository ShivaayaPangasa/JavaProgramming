
# Q04 - Maven WAR Plugin

## Aim
To configure a Maven project to build a web application using the Maven WAR Plugin.

## Files
- pom.xml: Configures Maven and the WAR plugin.
- index.jsp: Contains the welcome webpage.

## Concepts
- Maven build configuration
- WAR packaging
- Maven WAR Plugin

## Commands
mvn clean package

## Output
The WAR file is generated inside the target directory.
