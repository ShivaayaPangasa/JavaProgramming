# Q40 — Spring Boot POM and runnable application

This is a complete minimal Spring Boot web application. From this folder run:

```powershell
mvn spring-boot:run
```

Open `http://localhost:8080/hello`. To package it, run `mvn clean package`. It uses Spring Boot 3.5.16 and Java 17 for a familiar `spring-boot-starter-web` example; use a teacher-required version if specified.
